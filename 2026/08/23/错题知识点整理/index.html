按主题分类整理的错题知识点,已校对修正。标注「※修正」为原记录有误之处,「※补充」为原记录不完整之处。

一、服务器硬件管理(BMC / IPMI / PECI)

  1. IPMI(Intelligent Platform Management Interface,智能平台管理接口) 是一种开放标准接口协议,用于远程管理和监控服务器硬件状态。它通过 BMC(Baseboard Management Controller,基板管理控制器) 实现,提供带外管理(out-of-band) 功能——即使服务器操作系统崩溃,也能进行管理操作。
  2. BMC 通过 IPMI 监控 CPU 温度时,读数恒为 0,可能原因是 PECI(Platform Environment Control Interface,平台环境控制接口)未初始化。PECI 是 CPU 与 BMC 之间传递温度等遥测数据的专用接口。
  3. BMC(基板管理控制器) 负责监控和管理硬件状态(温度、电压、风扇、电源等)。
  4. BMC 冷重启(cold reset) 指完全断电后重启;热重启(warm reset)则指不断电仅复位固件。
  5. ※修正 BMC 固件只能通过 IPMI 协议控制远程服务器 → 错误。BMC 除了 IPMI 外,还支持 Redfish(基于 HTTPS/RESTful API,现代服务器主流)、SNMP、SSH、Web 管理界面等多种管理方式。IPMI 只是其中一种(且偏底层、安全性较差)。

二、固件与系统启动(UEFI / PXE / 多核启动)

  1. UEFI 使用 FAT32 文件系统(ESP,EFI System Partition)来引导操作系统。
  2. PXE(Preboot eXecution Environment,预启动执行环境):使用网卡启动,通过 TFTP(简单文件传输协议) 从 TFTP 服务器下载引导程序,实现无盘启动。
  3. 多核 x86 服务器启动时,从核(AP,Application Processor)的启动初始代码由主核(BSP,Bootstrap Processor)提供。BSP 负责初始化系统并引导 AP 进入实模式执行启动代码。

三、操作系统内核

  1. 内存屏障(Memory Barrier):※补充 为了提升性能,编译器和 CPU 会对指令进行重排序,但这可能破坏多线程/多核场景下的内存可见性。内存屏障用于禁止特定方向的重排,保证内存操作顺序:
    • 编译屏障:阻止编译器重排(如 barrier() 宏);
    • CPU 屏障:x86 上为 mfence(全屏障)/ lfence(读屏障)/ sfence(写屏障),ARM 上为 dmb / dsb / isb;
    • Linux 内核中常用 smp_mb() / smp_rmb() / smp_wmb() 等。
  2. RCU(Read-Copy-Update):允许读写操作并发执行,适用于读多写少的场景,通过延迟释放内存(宽限期后回收) 来确保数据一致性。
  3. OOM Killer:当系统内存严重不足时,内核会选择性地杀死某些进程以释放内存。
  4. 用户态进入内核态是通过系统调用(此外还有中断和异常)实现的。
  5. Linux 中可用于实时分析中断延迟的工具:ftrace、cyclictest(cyclictest 是 rt-tests 套件中的标准延迟测试工具)。
  6. 野指针出现的原因:
    • 指针没有初始化;
    • 被 free / delete 之后没有置为 NULL;
    • 指针指向了超出变量作用域的内存。
  7. ※修正 SDLC(系统调用周期) → 疑为笔误,不完整。SDLC 通常指 Software Development Life Cycle(软件开发生命周期);若原意是系统调用,正确表述为:系统调用(System Call)是应用程序请求内核服务的唯一入口,涉及用户态→内核态的切换、参数传递与返回。

四、虚拟化与 I/O

  1. KVM(Kernel-based Virtual Machine,内核虚拟机):基于硬件辅助(Intel VT-x / AMD-V)实现的完全虚拟化。
  2. ※修正 SR-IOV 和设备直通必须?intel UFd → 不完整/笔误。SR-IOV(Single Root I/O Virtualization,单根 I/O 虚拟化)与设备直通(Device Passthrough,即 PCI passthrough)需要 Intel VT-d(Directed I/O,直接 I/O 虚拟化,含 IOMMU)支持;AMD 平台对应 AMD-Vi / IOMMU。UFd 应为 VT-d 的误记。
  3. TLB(Translation Lookaside Buffer,转换后备缓冲器) ※补充:是 CPU 内部的高速缓存,用于缓存虚拟地址到物理地址的映射(页表项),加速地址转换;TLB 未命中时会触发页表遍历(Page Walk),性能显著下降。

五、网络

  1. VLAN(虚拟局域网):用来创建逻辑分区以隔离网络流量(二层隔离,需交换机支持 802.1Q)。
  2. QUIC 协议基于 UDP;当中间设备阻断 UDP 443 端口时,QUIC 无法工作,会退回 TCP 协议(HTTP/3 → HTTP/2)。

六、存储

  1. UFS(Universal Flash Storage,通用闪存存储):主要用于提供文件存储和访问(常见于移动设备、嵌入式系统的高速闪存)。

七、安全

  1. 防止 XSS(跨站脚本攻击)的常见方法:验证/过滤用户输入(输入校验、白名单),并在输出时进行转义/编码(HTML 实体编码),同时可配合 CSP(内容安全策略)。

八、调试与性能工具

  1. 调试内存池应优先使用的工具:Valgrind(Memcheck 检测内存泄漏、非法访问)。
  2. 线程和协程共享堆内存——线程共享所属进程的堆;协程(同一线程内)同样共享该线程的堆。
